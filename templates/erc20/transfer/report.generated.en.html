Send ERC-20 tokens from the SafeAI research

erc20/transfer

The Safe calls transfer directly on the token contract you pick, sending the amount you type to the recipient you pick. There is only one call. It goes through no router or other contract, and leaves no allowance.AI research

  • Address sources 5 / 5 All 5 addresses are confirmed in at least 2 places: the official page, the protocol API, CoinGecko, the vault's registered factory, the bug bounty scope, the SDK package or a shared deployer lists the same address.
  • Source verified 5 / 5 Sourcify's source, compiled again with a pinned compiler, gives exactly the code on chain, so the function definitions used to decode the transaction belong to these contracts.
  • Code unchanged 5 / 5 At each signing, the program checks that every contract the card uses still runs the code it was researched with. An upgrade or a replacement is stopped.
  • Parameter checks no tests The template has no argument that takes any value: each is bound to the card or to a fixed value, so nothing needs a perturbation test and none is recorded. At each signing, verify changes every bound argument one by one and checks that each becomes a MISMATCH.
  • Two providers Every chain read asks two providers; when they disagree, there is no result.

Next steps

  1. The first time you use this template, or after it changes, approve it
    bin/kiss-sign template approve erc20/transfer

    It prints the template, the commit of main on GitHub and the template's keccak256. Answer y only if it is the one you reviewed.

  2. When the recipient is not your Safe, first add it to your address book. Pick a name in lowercase English joined with -; get the address from a source outside the chat
    bin/kiss-sign book add <name> <address>

    It prints the name and the full address and asks Add this entry? [y/N]. Type y only after checking every character against a source outside the chat. Add each recipient once.

  3. Make the card
    bin/kiss-sign card new erc20/transfer

    When templates/ or registry/ in your clone differs from main on GitHub, it stops before asking anything and tells you to run git pull first.

  4. token: it lists each token you can pick, with its full address. Pick the one you want; both its name and its full address must be right.
  5. recipient: it lists your Safe and the names in your address book, each with its full address. Pick the one you want; its full address must be right.
  6. amount: type the amount of the token you pick in whole tokens, such as 1250.5; thousands commas are allowed, such as 1,000,611.448606.

    It prints it both in whole tokens and in base units; check that the number is what you want.

  7. It prints the whole card, each name with its full address, and asks Is this what you mean to do? [y/N]. Type y only if all of it is what you want.

    It prints Sealed card 0x…, the card's hash, which the next step uses.

  8. Propose the transaction in the Safe web app (the first time you use this template, start with a small amount), copy its safeTxHash, then run
    bin/kiss-sign verify --card <card hash> --safe-tx-hash <safeTxHash>

    MATCH: it prints the safeTxHash and the path of a page with the domain hash, the message hash and the checklist. Go on.

    MISMATCH or UNVERIFIABLE: do not sign. Read the checks it lists, then the AI judgment under "To review" in this report, which may explain why.

  9. Hardened tier: on an independent computer, run
    ./check.sh <nonce>

    Compare the hashes it computes with the hardware wallet, and its page's checklist row by row with the verify page.

  10. Compare the domain hash and the message hash on the hardware wallet character by character with the verify page. Sign only if they are the same.
    Comparethe domain hash and the message hash, each 0x followed by 64 characters

What the program does at each signing

  • The transaction has only this call, counting each call inside a MultiSend
  • Every argument follows the rules above, and encoding them again gives exactly the same bytes
  • After simulation, the the token you pick the Safe gives is exactly the amount you type
  • No allowance is higher after the transaction
  • Every registry contract the card uses still runs the code its code pin records
