Swap tokens on Uniswap, with a signed Permit2 allowanceAI research

uniswap/swap-permit

The Safe calls execute on Uniswap's Universal Router. It first uses PERMIT2_PERMIT to hand over a Permit2 allowance the Safe's signers signed beforehand (to the router, 2^160-1, 30 days), then runs V4_SWAP: in one v4 pool with no hook, it sells the amount you type, and all of the bought token goes to the Safe. The router's allowance in Permit2 stays after the transaction.AI research

  • Source verified 5 / 5 The source verified on Etherscan, compiled again with a pinned compiler, gives exactly the code on chain, so the function definitions used to decode the transaction belong to these contracts.
  • Code unchanged 7 / 7 At each signing, the program checks that every contract the card uses still runs the code it was researched with. An upgrade or a replacement is stopped.

  • Two providers Every chain read asks two providers; when they disagree, there is no result.

To review 4

The AI checked each item first and gives its advice.

The Permit2 allowance this transaction uses is a Safe message (EIP-1271) that the Safe's signers signed beforehand, and kiss-sign does not check that step. The template binds the allowance's contents in the transaction, so a wrongly signed one makes the transaction fail. But an allowance you were tricked into signing for someone else can be used without this transaction.AI research
AdviceWhen you sign the Permit2 message, check that the spender is Universal Router 0x23617e59A5925b2A4Bf75d73ff6711cD0b29De85.AI research
You type the card's "minimum to receive" yourself. The Uniswap app's trading API works out the slippage at each quote (auto slippage 0.5% to 5.5%), and the price comes from a route the API finds across many pools, which no view on chain can read.AI research
AdviceType the minimum to receive shown on the app's confirm screen. Do not type a lower one.AI research
The app picks the pool (fee and tick spacing). The template allows any pool and only requires that it has no hook. Anyone can open a v4 pool, so the only price protection is the minimum you type: below it, the router makes the transaction fail, and verify also gives MISMATCH.AI research
AdviceAcceptable. Always type the minimum to receive that the app shows.AI research
Allowances that stay after the transaction: the Safe's unlimited allowance to Permit2, and the 2^160-1, 30-day allowance to the Universal Router inside Permit2. The router pulls tokens only from the address that calls it, so only the Safe's own later transactions can use it.AI research
AdviceAcceptable. To revoke, call approve(Permit2, 0) on the token, or call lockdown on Permit2.AI research

  1. The first time you use this template, or after it changes, approve it

    bin/kiss-sign card new uniswap/swap-permit

    When templates/ or registry/ in your clone differs from main on GitHub, it stops before asking anything and tells you to run git pull first.
