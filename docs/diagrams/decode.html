2Decode the data yourself with cast (a real run on the same Data)
cast
$ PACKED=$(cast decode-calldata "multiSend(bytes)" $DATA)
$ CALL1=0x${PACKED:172:152}; CALL2=0x${PACKED:494:1624}
→ MultiSend packs its calls into one blob; you count the byte offsets of each call by hand
$ cast decode-calldata "approve(address,uint256)" $CALL1
0x4A6c312ec70E8747a587EE860a0353cd42Be0aE0
10001000000 [1e10]
→ lets 0x4A6c…0aE0 spend 10,001 USDC (USDC has 6 decimals)
$ BUNDLE=$(cast decode-calldata --json "multicall((address,bytes,uint256,bool,bytes32)[])" $CALL2)
→ call 2 is Bundler3's multicall, which holds two more calls
$ cast decode-calldata "erc20TransferFrom(address,address,uint256)" $(jq -r '.data[0][0][1]' <<< $BUNDLE)
0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48
